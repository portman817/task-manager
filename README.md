# Task Manager API

REST API for task management with JWT authentication and role-based authorization.

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Spring Data JPA
- Swagger / OpenAPI
- Maven

## Features

- User registration and login
- JWT authentication
- Role-based access control
- Current user endpoints
- Admin endpoints
- Task management
- Swagger API documentation
